# Saved rules

Place pasted rules here as UTF-8 text when browsing fails. Record the original URL,
retrieval time and original time-zone wording. Treat pasted project context as
unverified notes, not an official rule source.

`scripts/fetch_rules.py` writes a text snapshot and `.source.json` provenance file.
HTML extraction is basic: script-rendered content may be absent. Compare the
snapshot to the page before quoting, and retain the provenance with any checklist
you publish. Do not place API keys or private chat logs here.
